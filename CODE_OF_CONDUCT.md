# Code of Conduct

## Our Pledge

We are committed to fostering an open, welcoming, and respectful community for everyone, regardless of age, background, identity, experience, or skill level.

As contributors and maintainers of **Recon Automation Framework**, we pledge to make participation in this project a positive and harassment-free experience for all members of the community.

---

# Our Standards

Examples of behavior that contributes to a positive environment include:

- Being respectful and considerate.
- Providing constructive feedback.
- Accepting different viewpoints and experiences.
- Helping others learn and improve.
- Focusing on collaboration and technical discussion.
- Using welcoming and inclusive language.

Examples of unacceptable behavior include:

- Harassment, discrimination, or personal attacks.
- Offensive, abusive, or hateful language.
- Trolling or intentionally disruptive behavior.
- Publishing private or confidential information without permission.
- Spam or unrelated promotional content.
- Any conduct that could reasonably be considered inappropriate in a professional community.

---

# Scope

This Code of Conduct applies to all project spaces, including:

- GitHub Issues
- Pull Requests
- Discussions
- Documentation
- Project communications
- Any other official community channels related to this project

# Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

Maintainers may take appropriate action in response to unacceptable behavior, including:

- Requesting changes to behavior.
- Removing inappropriate content.
- Closing issues or pull requests.
- Temporarily or permanently restricting participation when necessary.
