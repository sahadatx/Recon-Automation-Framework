Thank you for helping improve the security of **Recon Automation Framework**.

The security of this project is taken seriously, and responsible disclosure is greatly appreciated.

| Version | Supported |
|----------|:---------:|

---

# Reporting a Vulnerability

If you discover a security vulnerability in this project, **please do not disclose it publicly**.

Instead, report it privately using one of the following methods:

- 📧 Email: **pentester.sahadathossain@gmail.com**
- 💼 GitHub Issues (for non-sensitive security discussions only)

Please include as much information as possible, including:

- A detailed description of the vulnerability
- Steps to reproduce the issue
- A proof of concept (if applicable)
- The affected module(s)
- Suggested remediation (optional)

---

# Responsible Disclosure

Please allow reasonable time for the vulnerability to be reviewed and addressed before making any public disclosure.

We kindly ask researchers to:

- Avoid public disclosure before a fix is available.
- Avoid accessing, modifying, or deleting data belonging to others.
- Test only systems you own or have explicit permission to assess.
- Avoid actions that may negatively impact service availability.

---

# Response Process

After receiving a valid vulnerability report, the project will:

1. Acknowledge receipt of the report.
2. Verify and reproduce the issue.
3. Develop and test an appropriate fix.
4. Publish the fix in a future release.
5. Credit the reporter when appropriate (with permission).

---

# Scope

This policy applies to:

- Core framework components
- Plugin system
- Reconnaissance modules
- Reporting engine
- Dashboard module
- Documentation-related security issues

Third-party tools and external services used by this project are outside the scope of this policy and should be reported to their respective maintainers.

---

# Security Best Practices

Users of this framework should:

- Keep Python and dependencies up to date.
- Protect API keys and credentials.
- Never commit sensitive information such as `.env` files.
- Run reconnaissance only against systems for which they have authorization.
- Review generated reports before sharing them publicly.
